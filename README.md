# EvoShift Homebrew tap

```sh
brew install evoshiftai/tap/evoshift
evoshift serve
```

Each EvoShift release writes its cask to `Casks/`. EvoShift itself is under the PolyForm Shield License 1.0.0 (see [evoshiftai/releases](https://github.com/evoshiftai/releases)); this tap's own files are MIT ([`LICENSE`](LICENSE)).
